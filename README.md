# DCF Valuation Model with Amortization and Sensitivity (Excel)

## Overview
This project presents an advanced Discounted Cash Flow (DCF) valuation model developed in Excel, designed to estimate enterprise value under different financial and market assumptions.

The model integrates debt amortization and sensitivity analysis, reflecting approaches commonly used in corporate finance and transaction advisory.

## Objective
To assess company valuation by projecting cash flows, incorporating financing structure, and evaluating the impact of key assumptions such as WACC and terminal growth rate.

## Key Components

### 1. Debt Amortization Schedule
- 5-year projection of debt structure
- Opening and closing balances
- Interest expense calculation
- Principal repayment dynamics
- Input-driven flexibility

### 2. DCF Valuation Framework
- Forecasted cash flows
- Discounting using WACC
- Terminal value estimation

### 3. Sensitivity Analysis
- Two-dimensional sensitivity table
- Variables:
  - WACC
  - Terminal growth rate (g)
- Scenario-based valuation insights

## Methodology
The model applies standard DCF techniques combined with structured debt modeling. Sensitivity analysis is used to evaluate valuation robustness under varying market conditions.

## Use Cases
- Corporate valuation
- Investment decision support
- Financial modeling practice
- Transaction advisory analysis

## Tools
- Microsoft Excel

## Notes
This model is a simplified representation of real-world financial models used in advisory and valuation projects.
